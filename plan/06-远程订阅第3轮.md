# 06 远程订阅第 3 轮：订阅正确性 / 更新检查 / 僵尸清理

来源：loop-5 第 3 轮 subagent 调研（挂账候选逐条核实）。

## 调研结论（本轮依据）

1. **深层布局 + plugin 清单 = 订阅正确性缺口（高）**：scan.js:27-46 只认一级（或 `<dir>/skills` 一层），
   `skills/<类目>/<name>/SKILL.md` 两层布局与 `.claude-plugin/marketplace.json` 声明的路径都读不到
   ——订阅 anthropics/skills 这类官方仓读到 0 个 skill，`hub check` 只报「空源」。
   参考实现：skills.ts:284-308（容器目录 3 层、遇 skill 即停）、plugin-manifest.ts:51-112。
2. **本地源没有「更新检查」（高，代码债合体）**：只有远程订阅有四态报表；本地订阅源（用户自己
   git pull 的仓库）没有任何前后对比。更刺眼的是 scan.js:98-106 的 snapshotSkills 是**死代码**
   ——注释还在描述「store.remoteSources[path].skills 下次拉取前后对比」，而 store.js 已废弃
   remoteSources：功能没做、接口留着、注释还在撒谎。
3. **updateRemote 僵尸实体（中）**：remote-repo.js:267-272 只按 frontmatter name 匹配上游；
   上游改名即报 removed，实体+台账原样留存，每次 update 重复报——只能手删。
   参考实现 skill-relocation.ts:27-74：按锁定路径重定位。
4. **文案残迹（低）**：actions.remote.js:16,46,56,65,86 与 renders.js:319-328 出现
   「远程订阅 里」「远程订阅 清单」这类悬空空格（模板占位符删剩的）。
5. **CliHints 不分页（中）**：CliHints.jsx:11 只按 module 过滤，远程订阅页列出全部 skills 命令。

## 本轮需求

### 1. 深层目录发现 + plugin 清单（订阅正确性）
- scan.js：来源侧扫描向下走最多 3 层、跳过点开头目录、**遇 SKILL.md 即停**（浅层遮蔽深层）；
  目标侧维持一级（迁移产物本来就是平铺）。
- 解析 `.claude-plugin/marketplace.json`（plugins[].skills[] + metadata.pluginRoot）与
  `.claude-plugin/plugin.json`（skills[]）声明为补充根，不受 3 层限制，去重。
- 验收：两层类目布局与 marketplace 声明路径都能导入；单测覆盖 遮蔽语义/混合布局/清单声明。

### 2. `skill hub refresh [source]`：订阅源更新检查
- 重新扫描订阅源，与 store 里存的上次快照对比，报告 +新增/-移除/~变更 并刷新快照
  （本地源：用户 git pull 之后跑这条看上游改了什么；不越「不管 git」的边界——pull 仍归用户）。
- 远程订阅仓库：refresh 同时把台账 hash 与磁盘对齐（兜住手工改动，update 的基准不再漂）。
- 快照存 `store.sourceSnapshots`（sourcePath → { skills, scannedAt }）。
- 验收：改夹具后 refresh 报出三类变更；远程仓库手工改动被 refresh 对齐。

### 3. updateRemote 改名重定位 + --prune
- 上游按 name 找不到时，先按台账里的 skillPath（原目录名）在上游找一次——找到即视为改名，
  照常更新（报 updated）；仍找不到才报 removed。
- `--prune`：removed 的同时清实体+台账（消僵尸）。
- 验收：上游改目录名（frontmatter name 不变）→ updated；改 name → removed（--prune 后实体消失）。

### 4. 顺手整洁
- 清「远程订阅 里」「远程订阅 清单」等悬空空格。
- CliHints 加 `only` prop（按 action id 前缀过滤），远程订阅页只列本页相关命令。
