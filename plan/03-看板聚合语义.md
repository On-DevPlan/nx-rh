# 03 看板 = 聚合视图：一仓库可入多主题（P1）

来源：KV 任务「repos 固定，看板主题只是用于聚合——把 nx 系列聚成一个主题；
fr / goah / goco(devctr) 聚进「fr常用」；fr / mn-rt / goah 聚进「远程打字」；
不同项目可以聚合在不同主题里」。

## 语义修正（对 plan/02 的收窄）

plan/02 把拖拽实现成了「移动」（进新板自动摘出旧板）。用户要的是**聚合**：
repos 固定，看板只是聚合视图——同一仓库可以同时出现在多个主题里
（fr 既在「常用」也在「远程打字」）。落库机制（`boards[].repoIds` 有序引用、
删板回未分组、删登记同步摘引用、导入即聚合）不变，只改 assign 的语义与面板文案：

- 加入看板**不再摘其他看板的成员关系**；已在板内再 assign = 按 before 调位次（幂等）
- 新增移除路：`--remove --board <id>` 从该板移出（其他板保留）；
  `--remove` 不带 board = 从所有板移出（回未分组）
- 面板：拖进看板 = 聚合进来；拖到未分组区 = 从所有看板移出；
  板内卡片 hover 多一颗「移出」（只摘本板）

## 配置（用户点名的真实聚合，写进登记 store）

| 看板 | 成员 |
| --- | --- |
| nx系列 | nx-as / nx-bt / nx-kn / nx-kv / nx-nx / nx-pg / nx-pn / nx-rh / nx-rp / nx-sk（全部 nx-*） |
| fr常用 | fr / go-ah / dev_ctr_hello（「goco/devctr」按现登记映射到 dev_ctr_hello） |
| 远程打字 | fr / mn-rt / go-ah（fr 客户端 + mn-rt RemoteType 服务 + go-ah 认证中心） |

注：「goco」在登记与磁盘都没有对应目录，按最接近的 dev_ctr_hello 处理；
若另有所指，`nx-rh board assign <repo> --board <fr常用id>` 一条命令补进。

## 验收

- [ ] 同一仓库聚合进两个看板后，两边都在、清单计数正确
- [ ] `--remove --board` 只摘一板；不带 board 全摘回未分组
- [ ] 面板拖拽：跨板拖不丢原板成员；卡片「移出」只摘本板；拖到未分组全摘
- [ ] 三块用户点名的看板在真实登记 store 里配置完成（fr / go-ah 双板共存）
- [ ] `pnpm test` 全绿（存量 2 个 wt 失败除外）
